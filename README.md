# ☯ BẢNG CÔNG ĐỨC VÔ LƯỢNG (NAM TÀO LINH BẢNG)

Website tri ân và vinh danh danh sách người donate cúng dường theo phong cách tâm linh, bùa chú ma mị xen lẫn hài hước.

---

## 🌟 Tính Năng Nổi Bật

1. **Bảng Xếp Hạng Linh Giới (Leaderboard)**:
   - **Tam Đại Hộ Pháp Chí Tôn (Top 1 - 2 - 3)**: Bục vinh danh Kim Thân Bồ Tát (Quán Quân với vòng kim quang rực rỡ), Nhị Vị & Tam Vị.
   - **Phân Bậc Tu Vi**: Thái Thượng Hộ Pháp (>2M), Đại Thí Chủ (1M - 2M), Chân Nhân (500K - 1M), Tiên Phong Đạo Hữu (200K - 500K), Thiện Nam Tín Nữ (<200K).
   - **Bộ lọc & Tìm kiếm**: Lọc theo tu vi, tìm kiếm theo tên hoặc lời nguyện.

2. **Tương Tác Tâm Linh Độc Đáo**:
   - **Quả Mõ Nổi (Gõ Mõ Tích Đức)**: Nhấp chuột phát âm thanh "Cốc!" chuẩn xác bằng Web Audio API, chữ bay lên (`+1 Công Đức`, `Deadline Tiêu Tan`, `Không Còn Bug`...).
   - **Bái Lạy Tăng Phúc**: Người xem có thể bấm nút "🙏 Bái" để tích thêm phúc khí cho từng người cúng dường.
   - **Sớ Tri Ân (Modal Cuộn Sớ)**: Mở cuộn sớ giấy vàng khắc chữ chu sa và triện đỏ Nam Tào chứng nhận công đức.
   - **Mã QR Cúng Dường**: Hỗ trợ quét mã VietQR chuyển khoản trực tiếp.

3. **Cõi Trời Cai Quản (`/god`)**:
   - Truy cập qua đường dẫn: `http://localhost:3000/god`
   - **Mật mã khai cổng (PIN)**: `tamlinh68` (có thể đổi trong cài đặt)
   - Thống kê toàn cảnh: Tổng linh thạch, số thiện tín, tổng lượt bái lạy.
   - **CRUD Sổ Nam Tào**: Thêm mới thiện tín, sửa đổi danh xưng, số tiền, di ngôn, ẩn/hiện hoặc xoá vĩnh viễn.
   - **Thiên Quy Cài Đặt**: Đổi tiêu đề bảng, câu châm ngôn, sớ thông báo, tài khoản ngân hàng, mã PIN.

## 🚀 Khởi Chạy Dự Án

```bash
# Cài đặt thư viện (nếu chưa cài)
npm install

# Chạy môi trường phát triển
npm run dev
```

Mở trình duyệt:
- Giao diện người dùng: [http://localhost:3000](http://localhost:3000)
- Trang Quản trị Thần Thánh: [http://localhost:3000/god](http://localhost:3000/god) (PIN: `tamlinh68`)
